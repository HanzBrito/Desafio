 Classificador de Nível de Heróis

Projeto desenvolvido em JavaScript para praticar conceitos fundamentais de lógica de programação e estruturas condicionais.

O programa recebe o nome de um herói e sua quantidade de XP (experiência) e, de acordo com a quantidade de XP, determina o nível correspondente.
